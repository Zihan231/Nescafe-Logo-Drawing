Nescafe Inspired Vector Bold

A design study based on the user-provided vector artwork. The letters A, C, E, F, S use the source outline geometry, normalized to font metrics. The remaining characters are drawn from DejaVu Sans Condensed Bold (original source license available at dejavu-fonts.org). The letter N in the supplied logo is merged with a trademark flourish, so it is not included directly. This is not the genuine NESCAFÉ corporate typeface, nor a fully faithful reproduction.
